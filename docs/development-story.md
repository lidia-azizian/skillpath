# How I Built SkillPath

## Project Overview

SkillPath is a personal learning tracker designed to help users organize goals, record practice sessions, manage resources, and monitor progress across different skills and hobbies.

## AI-Assisted Development

I created SkillPath as an experiment to explore how AI coding agents can support software development.

Using **GitHub Copilot in VS Code**, I guided the development process through natural-language prompts, defining requirements, reviewing generated solutions, testing features, and refining the application iteratively.

## Technologies Used

React, TypeScript, Vite, Node.js, Gemini API, Git, GitHub, and Cloudflare Pages.

## What I Learned

- How to communicate requirements effectively to AI coding agents.
- Why reviewing and testing AI-generated code is essential.
- How to manage a project using Git and GitHub.
- How to deploy a web application and handle API keys securely.

## Final Result

A publicly accessible web application with learning goals, progress tracking, a practice journal, and resource management. AI-powered planning and reflection features are available when running the project locally.
